Build

Linux / macOS

cmake -B build
cmake --build build

Produces build/htserve.

Windows (MinGW-w64 cross-compile from Linux)

Use the toolchain file in cmake/ and the helper script in scripts/:

cmake -B build-win-cmake -DCMAKE_TOOLCHAIN_FILE=cmake/mingw-w64-x86_64.cmake
cmake --build build-win-cmake

Produces build-win-cmake/htserve.exe, which links against ws2_32 for Winsock.

Requirements

  • C99 compiler (gcc, clang, MSVC, MinGW-w64).
  • CMake 3.x.
  • POSIX threads on Unix; Winsock2 on Windows (linked automatically).
