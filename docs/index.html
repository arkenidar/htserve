htserve

Minimal C99 static-file HTTP server. Single source file, no dependencies beyond the C standard library and the platform sockets API. Builds on Linux and Windows (MinGW-w64 cross-compile supported).

Usage Build Features & limitations

At a glance

cmake -B build && cmake --build build
./build/htserve --public ./site --port 9000
